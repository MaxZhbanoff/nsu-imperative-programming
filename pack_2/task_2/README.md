# Задача 2. Суммы k-ых

Дан массив из $N$ чисел: $a_{1},a_{2},\dots,a_{N}$.
Требуется вывести $𝑁$ чисел $𝑡_{k}$ $(𝑘 = 1, . . ., 𝑁)$, где $𝑡_{k}$ — сумма элементов массива с шагом $𝑘$:
$t_{k}=\sum a_{j*k}$

Т.е. $𝑡_{1}$ равняется сумме всех элементов массива, $𝑡_{2}$ равняется сумме каждого второго элемента массива, 
$t_{3}$ равняется сумме каждого третьего элемента и т.д.

## Формат ввода
В первой строке записано целое число $𝑁$ $(1 ⩽ 𝑁 ⩽ 10^5)$. 
Во второй строке через пробел записано $𝑁$ целых чисел $𝑎_{i} (1 ⩽ 𝑎_{i} ⩽ 10^4 )$.

## Формат вывода
Выведите $𝑁$ строк: в $𝑘$-й строке выведите значение $𝑡_{k}$.

## Пример 1
**Ввод:** 
6  
4 3 5 1 2  
**Вывод:**   
24   
13  
14  
1  
2   
9
