# Задача 4. Проверка на простоту

В файле записано целое число $N (1 \le N \le 10000)$. Нужно вывести YES, если оно является простым, и NO в противном случае.

## Формат ввода
Одно целое число $N$.

## Формат вывода
Строка YES или NO.

## Пример 1
**Ввод:** 
5
**Вывод:** 
YES

## Пример 2
**Ввод:** 
4
**Вывод:** 
NO

## Пример 3
**Ввод:** 
13
**Вывод:** 
YES
