# Задача 5. Деление нацело

В файле записано два целых числа $A$ и $B$. Оба числа по модулю не превышают 10000, число $B$ положительное. Требуется найти четыре значения: частное $A/B$, округлённое вниз; частное, округлённое вверх; частное, округлённое в сторону нуля; остаток $R$ от деления ($0 \le R < B$).

## Формат ввода
Два целых числа $A$ и $B$.

## Формат вывода
Четыре целых числа через пробел, согласно условию.

## Пример 1
**Ввод:**   
7 3  
**Вывод:**   
2 3 2 1  

## Пример 2
**Ввод:**   
-100 3  
**Вывод:**   
-34 -33 -33 2  

## Пример 3
**Ввод:**   
10 5  
**Вывод:**   
2 2 2 0
