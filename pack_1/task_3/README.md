# Задача 3. Сумма чётных

Дана последовательность целых чисел, требуется посчитать сумму всех её чётных элементов.

## Формат ввода
В первой строке содержится целое число $N (1 \le N \le 100)$ — количество элементов последовательности. Во второй строке записано $N$ целых чисел через пробел.

## Формат вывода
Выведите одно число: сумму всех чётных элементов последовательности.

## Пример 1
**Ввод:**  
8  
2 3 7 6 8 3 1 2  
**Вывод:**   
18  

## Пример 2
**Ввод:**   
3  
1 3 5  
**Вывод:**   
0  

## Пример 3
**Ввод:**   
4  
2 2 2 2  
**Вывод:**   
8
