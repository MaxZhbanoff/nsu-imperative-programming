# Задача 5. Функция
Пусть $𝑃$ — множество целых чисел от $1$ до $𝑁$. Задано отношение $𝑅$ на множестве $𝑃 × 𝑃$. 
Отношение задаётся списком принадлежащих ему элементов: множеством пар $(𝑥, 𝑦) ∈ 𝑃 ×𝑃$. 
Для заданного отношения $𝑅$ требуется определить: 
1. Является ли 𝑅 функцией: ∀𝑥 ∈ 𝑃: (𝑥, 𝑢) ∈ 𝑅 и (𝑥, 𝑣) ∈ 𝑅 ⇒ 𝑢 = 𝑣 — отсутствует многозначность. 
2. Является ли 𝑅 всюду определённой функцией: 𝑅 является функцией и 
$∀𝑥 ∈ 𝑃 \space \space ∃ \space 𝑦 \space|\space (𝑥, 𝑦) ∈ 𝑅$  — значение определено на всём множестве 𝑃.
3. Является ли 𝑅 инъективной функцией: 𝑅 является функцией и $(𝑥, 𝑢) ∈ 𝑅$ и $(𝑦, 𝑢) ∈ 𝑅 ⇒ 𝑥 = 𝑦$.
4. Является ли 𝑅 сюръективной функцией: 𝑅 является функцией и $∀\space𝑢 ∈ 𝑃 \space∃\space 𝑥 \space|\space (𝑥, 𝑢) ∈ 𝑅$.
5. Является ли $𝑅$ биективной функцией: функция $𝑅$ и инъективна, и сюръективна.

## Формат ввода
Первая строка входного файла содержит два целых числа $𝑁$ и $𝑀$, записанных через пробел — 
размер множества $(1 ⩽ 𝑁 ⩽ 300)$ и количество пар $(1 ⩽ 𝑀 ⩽ 𝑁^2 )$. В следующих $𝑀$ строках 
записано по два целых числа $𝑥$ и $𝑦$ $(1 ⩽ 𝑥, 𝑦 ⩽ 𝑁)$ — элементы отношения $𝑅$. Гарантируется, что все пары различны

## Формат вывода
Если отношение $𝑅$ не удовлетворяет ни одному из описанных свойств (то есть не является функцией), 
то выведите число $0$. В противном случае выведите через пробел в порядке увеличения номера свойств, 
которыми обладает отношение $𝑅$.

## Пример 1
**Ввод:**   
3 5  
1 2  
3 3  
1 3  
1 1  
2 1  
**Вывод:**   
0  
## Пример 2
**Ввод:**   
5 2   
1 3  
2 3  
**Вывод:**   
1  
## Пример 3
**Ввод:**  
5 2  
1 3  
2 5  
**Вывод:**   
1 3  
## Пример 4
**Ввод:**   
3 3  
1 1  
2 3  
3 2  
**Вывод:**  
1 2 3 4 5
