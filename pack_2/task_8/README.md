# Задача 8. Слова
В единственной строке файла записан набор слов, разделённых символами точки. 
Каждое слово состоит из букв латинского алфавита. Между словами находится один 
или несколько символов точки. До первого слова и после последнего точки могут 
быть, а могут не быть. В строке может быть записано всего одно слово, а может 
и вовсе не быть слов. Длина заданной строки находится в диапазоне от $1$ до $10 000$.
Требуется вывести одно целое число — количество слов в строке.

## Пример 1
**Ввод:**   
..ko..Privet.kreved....ko...  
**Вывод:**   
4
