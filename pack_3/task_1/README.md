# Задача 1. Распечатать время
Требуется реализовать функцию, которая распечатывает в выходной файл время, и решить с её помощью тестовую задачу.
Функция должна иметь сигнатуру: 
``` c
void printTime(int h, int m, int s);
```
Здесь $h$–количество часов (от 0 до 23), $m$ и $h$ —количество минут и секунд соответственно (от 0 до 59).
## Формат ввода
В первой строке содержится целое число $N$ — количество времён в файле $(2 ⩽ N ⩽ 1000)$. В каждой из следующих $N$ строк описано время в формате трёх целых чисел: $h, m, s$.
## Формат вывода
Нужно вывести $N$ строк, по одной дате в строке, в формате $HH:MM:SS$ (см. пример).
## Пример 1
**Ввод:** 
3  
12 37 59  
1 1 1  
23 59 59  
**Вывод:**  
12:37:59  
01:01:01  
23:59:59
