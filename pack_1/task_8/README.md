# Задача 8. Часы

Часы показывают время в 24-часовом формате. Записывается число часов $H$, минут $M$ и секунд $S$. Нужно определить, что часы будут показывать через $K$ секунд.

## Формат ввода
Четыре целых числа: текущие показания часов $H$, $M$, $S$ и количество секунд $K$.

## Формат вывода
Три целых числа $H'$, $M'$, $S'$ — показания часов через $K$ секунд. Ведущие нули печатать не нужно.

## Пример 1
**Ввод:**  
12 34 9 57  
**Вывод:**   
12 35 6  

## Пример 2
**Ввод:**   
23 59 59 1  
**Вывод:**   
0 0 0  

## Пример 3
**Ввод:**   
0 0 0 3600  
**Вывод:**   
1 0 0
