# Задача 3. Гистограмма

Дан массив из $N$ чисел: $a_{0},a_{1},\dots,a_{N-1}$.
Постройте гистограмму значений элементов массива: для каждого значения подсчитайте сколько раз оно встречается в массиве.

## Формат ввода
В первой строке записано целое число $𝑁 (1 ⩽ 𝑁 ⩽ 10^5 )$.
Во второй строке через пробел записано $𝑁$ целых чисел $𝑎_{i}(1 ⩽ 𝑎𝑖 ⩽ 10^4 )$

## Формат вывода
Для каждого значения, которое встречается в массиве хотя бы раз, выведите сколько раз оно 
присутствует среди элементов массива в формате: “значение: количество”.
Значения требуется выводить в порядке возрастания.
Для вывода двух целых чисел, разделённых двоеточием с пробелом, удобно использовать функцию printf со следующей форматной строкой: 
```c
printf ("%d:␣%d", value , count );
```
## Пример 1
**Ввод:**   
10   
3 4 5 10 3 4 10 1 1 3  
**Вывод:**   
1: 2   
3: 3  
4: 2  
5: 1  
10: 2
