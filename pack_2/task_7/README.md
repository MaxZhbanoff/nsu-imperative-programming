# Задача 7. Навести порядок
Дан массив, состоящий из $𝑁$ целых чисел. Требуется вывести эти $𝑁$ чисел в выходной файл, 
но в строго определённом порядке. Каждое следующее выведенное число должно быть больше 
предыдущего или равно ему.

## Формат ввода
В первой строке записано целое число $𝑁$ $(1 ⩽ 𝑁 ⩽ 10^4 )$ — количество элементов 
массива. Во второй строке через пробел записано $𝑁$ целых чисел, каждое из которых
по модулю не превосходит $10^5$ .

## Формат вывода
В единственной строке выведите все $𝑁$ элементов массива через пробел в указанном порядке.

## Пример 1
**Ввод:**  
5   
1 4 3 5 3  
**Вывод:**   
1 3 3 4 5
