# Задача 2. Развернуть строку
Требуется реализовать функцию, которая будет разворачивать заданную строку. Функция должна иметь сигнатуру:
``` c
void reverse(char *start, int len);
```
Здесь $start$ — указатель на начало строки (т.е. на первый её символ), а $len$ — количество символов в ней (исключая завершающий нулевой символ).
## Формат ввода
В первой строке содержится целое число $N$ — количество строк в файле $(2 ⩽ N ⩽ 1000)$. В каждой из следующих $N$ строк записана одна строка, которую нужно развернуть. Строка состоит только из символов латинского алфавита, и её длина лежит в диапазоне от $1$ до $100$ включительно.
## Формат вывода
Нужно вывести $N$ развёрнутых строк.
## Пример 1
**Ввод:** 
4 
C 
is
cool 
language
**Вывод:** 
C 
si 
looc 
egaugnal

---
**ЖБАНОВ МАКСИМ ЕВГЕНЬЕВИЧ**
