# Задача 4. Сумма

Дан массив из $N$ чисел: $a_{0},a_{1},\dots,a_{N-1}$.
Требуется найти два индекса $𝐿$ и $𝑅$ $(𝐿 ⩽ 𝑅)$ таких, что сумма $𝑎_{L} + 𝑎_{L+1} + . . . + 𝑎_{R-1} + 𝑎_{R}$ 
будет максимальной.

## Формат ввода
В первой строке записано целое число $𝑁 (1 ⩽ 𝑁 ⩽ 5000 )$.
Во второй строке через пробел записано $𝑁$ целых чисел, каждое из которых по модулю не превосходит 10 000.

## Формат вывода
Выведите три целых числа через пробел: $𝐿$, $𝑅$ и сумму элементов с индексами от $𝐿$ до $𝑅$. 
Если существует несколько вариантов выбрать такие 𝐿 и $𝑅$, что сумма элементов будет максимальной, 
то требуется вывести вариант с минимальным $𝐿$. Если существует несколько с минимальным $𝐿$, то с
реди таких требуется выбрать вариант с минимальным $𝑅$.

## Пример 1
**Ввод:**  
3  
1 2 3  
**Вывод:**   
0 2 6  
## Пример 2
**Ввод:**   
5   
1 -2 3 4 5  
**Вывод:**   
2 4 12  
## Пример 3
**Ввод:**   
4  
2 -2 1 1  
**Вывод:**   
0 0 2
