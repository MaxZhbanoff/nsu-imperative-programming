# Задача 1. Сравнение элементов

Дан массив из $N$ чисел: $b_{1},n_{2},\dots,b_{N}$.
Требуется для каждого элемента массива $b_{i}$ посчитать количество элементов $𝑏_{j}$ , стоящих правее $(𝑖 < 𝑗)$, но меньших него $(𝑏_{i} > 𝑏_{j})$.

## Формат ввода
В первой строке записано целое число $𝑁$ $(1 ⩽ 𝑁 ⩽ 100)$. Во второй строке через пробел записано $𝑁$ целых положительных чисел — значения элементов массива. Гарантируется, что значения элементов не превосходят 100.
## Формат вывода
Выведите $𝑁$ целых чисел через пробел: по порядку для каждого элемента входного массива выведите количество элементов, удовлетворяющих описанному выше условию.

## Пример 1
**Ввод:**   
4  
4 3 5 1 2  
**Вывод:**   
3 2 2 0 0  

## Пример 2
**Ввод:**   
3 3 2 1  
**Вывод:**   
2 1 0  

## Пример 3
**Ввод:**   
4 1 2 3 3  
**Вывод:**   
0 0 0 0
